## ◈ About This Repository

This repository documents my completion of **AI Fluency: Framework & Foundations**, a free course from Anthropic on Coursera. It contains structured notes, key concepts, and takeaways covering the **4D Framework** — a durable, model-agnostic approach to collaborating with AI systems effectively, efficiently, ethically, and safely.

```yaml
course     : AI Fluency, Framework and Foundations
platform   : Coursera (Community Impact)
instructor : Anthropic Academy
developed  : with Prof. Rick Dakan (Ringling College of Art and Design)
             and Prof. Joseph Feller (University College Cork)
duration   : ~3 hours, 10 modules
framework  : 4D, Delegation - Description - Discernment - Diligence
modes      : Automation - Augmentation - Agency
```

---

## ◈ Course Overview

The course introduces AI Fluency as a durable skillset, not a set of disposable tips tied to one tool or model. It builds a mental model of generative AI itself, then walks through the four core competencies of the 4D Framework and how they combine into a practical, repeatable loop for working with AI on real projects.

| # | Module | Core Focus |
|---|---|---|
| 1 | Introduction to AI Fluency | Course orientation, why collaboration over technology |
| 2 | The AI Fluency Framework | Fluency vs. literacy, the 4D competencies, 3 modes |
| 3 | Deep Dive — What is Generative AI (Part 1) | Mental model of generative AI, capabilities & limits |
| 4 | Delegation | Deciding what to hand to AI vs. do yourself |
| 5 | Description | Turning intent into effective prompts |
| 6 | Deep Dive — Effective Prompting Techniques | Six core prompting techniques |
| 7 | Discernment | Evaluating AI output critically |
| 8 | The Description–Discernment Loop | Iterating Description and Discernment together |
| 9 | Diligence | Acting responsibly: Creation, Transparency, Deployment |
| 10 | Conclusion | Bringing the framework together, ongoing practice |

## ◈ Module 2 — The AI Fluency Framework

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Fluency vs. Literacy**
AI *literacy* is knowing facts about AI. AI *fluency* is the practical, applied skill of working *with* AI — closer to language fluency than to passing a knowledge quiz.

**The 4D Framework**

| Competency | Question It Answers |
|---|---|
| Delegation | What should I hand off to AI, and what should I keep doing myself? |
| Description | How do I clearly communicate the task to the AI? |
| Discernment | How good is the AI's output, really? |
| Diligence | Am I using and sharing this responsibly? |

**Three Modes of Working with AI**

| Mode | Description |
|---|---|
| Automation | AI executes a well-defined task with minimal human involvement |
| Augmentation | Human and AI work together, each contributing distinct strengths |
| Agency | AI operates with greater autonomy toward a broader goal |

**Key Skills Gained**
- Distinguish AI fluency from AI literacy
- Map the 4D competencies onto Automation, Augmentation, and Agency

</details>

## ◈ Module 3 — Deep Dive: What is Generative AI

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Generative AI Fundamentals**
- How generative models differ from earlier, narrower AI systems
- Context windows — the "working memory" a model has for a conversation
- Emergent capabilities — abilities that appear at scale without being explicitly programmed

**Capabilities & Limitations**

| Where Models Shine | Where Models Struggle |
|---|---|
| Drafting, summarizing, brainstorming | Precise, verifiable factual claims |
| Pattern recognition across large context | Knowledge cutoffs — no awareness of recent events |
| Adapting tone, format, and style | Hallucinations — confident but incorrect output |
| Rapid iteration on structured tasks | Complex, multi-step reasoning under ambiguity |

**Key Skills Gained**
- Build a working mental model of how generative AI behaves
- Reason about AI outputs instead of treating the model as a black box

</details>

## ◈ Module 4 — Delegation

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Deciding What to Delegate**
Delegation is the judgment call of what work goes to AI versus what stays with the human. It rests on three things:

- **Your goals** — what outcome actually matters here
- **Platform capabilities** — an honest read of what the AI tool can and can't do
- **Task distribution** — strategically splitting work between yourself and the AI

**Practice Project**
The module has you scope a real project and produce a **delegation plan** — a document you carry forward and execute across the rest of the course.

**Key Skills Gained**
- Evaluate AI capabilities honestly rather than over- or under-trusting them
- Produce a delegation plan for a real, multi-step project

</details>

## ◈ Module 5 — Description

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**From Intent to Prompt**
The AI can't read your mind — clear description is what closes that gap. Description breaks down into three components:

| Component | Covers |
|---|---|
| Product Description | What the output should look like |
| Process Description | How the AI should go about producing it |
| Performance Description | The interaction style, tone, or role the AI should take |

**Key Skills Gained**
- Move from ad-hoc prompting to a structured description approach
- Articulate output, method, and interaction style explicitly

</details>

---

## ◈ Module 6 — Deep Dive: Effective Prompting Techniques

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Six Core Prompting Techniques**

```yaml
1_context:      Provide relevant background before the ask
2_examples:     Show the pattern you want (few-shot style)
3_constraints:  Define boundaries — length, format, scope
4_decomposition: Break a complex task into smaller steps
5_reasoning_first: Ask the model to reason before answering
6_role_or_tone: Assign a persona or voice for the response
```

**Recognizing a Prompt That Needs Rework**
Experienced practitioners watch for signs an output missed the mark — vagueness, wrong scope, wrong tone — and treat that as a signal to revise the prompt rather than accept the result.

**Key Skills Gained**
- Apply the six techniques to make prompts reliably effective
- Diagnose and rework prompts that aren't producing useful output

</details>

## ◈ Module 7 — Discernment

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Evaluating AI Output**
Discernment is the natural counterpart to Description: Description shapes what goes in, Discernment shapes how you respond to what comes out.

| Check | What You're Looking For |
|---|---|
| Output quality | Does it actually meet the Product Description? |
| Reasoning integrity | Are there gaps, contradictions, or unsupported claims? |
| Collaborative behavior | Does the AI's approach need to be redirected? |

**Key Skills Gained**
- Assess AI output quality rather than accepting it at face value
- Detect flawed reasoning and recognize when to redirect the AI's behavior

</details>

---

## ◈ Module 8 — The Description–Discernment Loop

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Turning Two Competencies into One Cycle**

```
Describe → Observe Output → Discern Quality → Refine Description → Repeat
```

This loop is applied to the same multi-step project from Module 4, refining prompts based on what comes back and adjusting the AI's behavior as the work progresses — turning the abstract framework into practiced habit.

**Key Skills Gained**
- Run an iterative Description–Discernment cycle on a real project
- Build the habit of refining prompts based on observed output

</details>

---

## ◈ Module 9 — Diligence

<details>
<summary><b>View Key Concepts</b></summary>

<br/>

**Acting Responsibly with AI**
Diligence is the ethical foundation of AI collaboration, viewed through three lenses:

| Lens | Question |
|---|---|
| Creation | How do I choose and engage with AI systems in the first place? |
| Transparency | How do I communicate the AI's role to others affected by the work? |
| Deployment | How do I take ownership of what I produce and share? |

**Context Matters**
Norms for disclosure and ownership shift by setting — academic, professional, creative — and meeting the norms of the context you're in is itself part of fluent AI use.

**Key Skills Gained**
- Apply the Creation–Transparency–Deployment lens to real decisions
- Recognize that responsible AI use is context-dependent, not one-size-fits-all

</details>
